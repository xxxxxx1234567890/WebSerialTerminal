# Modbus RTU 主视图 + 循环发送 — 设计文档

## 概述

在 WebTerm Pro 中为 Modbus RTU 调试工具增加主视图模式和循环发送功能。Modbus 激活时终端主区域切换为 Modbus 调试视图，解决右侧工具栏空间不足的问题。

## 布局

Modbus 激活时，终端输出区域隐藏，Modbus 视图在主区域显示：

```
┌──────┬─────────────────────────────────────────┬─────────┐
│ 左侧  │  ┌─ 请求构建器 ──────────────────────┐  │ 右侧栏  │
│ 侧边栏 │  │ [从站ID▼] [功能码▼] [地址] [数量]  │  │ 保留现有 │
│ (不变) │  │ [写入数据:                 ]      │  │ 工具面板 │
│       │  │ DEC/HEX  ⟳ 循环间隔: [1000]ms     │  │ (无变化) │
│       │  │ [▶ 发送] [⟳ 开始循环] [■ 停止]     │  │         │
│       │  ├─ TX/RX 帧 ────────────────────────┤  │         │
│       │  │ TX → 01 03 00 00 00 0A ...       │  │         │
│       │  │ RX ← 01 03 14 00 01 ... (响应时间) │  │         │
│       │  ├─ 响应解析 ────────────────────────┤  │         │
│       │  │ 寄存器表格 / 线圈灯 / 异常码       │  │         │
│       │  ├─ 日志 ────────────────────────────┤  │         │
│       │  │ [时间] [FC摘要] [状态]             │  │         │
│       │  └──────────────────────────────────┘  │         │
└──────┴─────────────────────────────────────────┴─────────┘
```

## 视图切换

- 在 `terminal-wrapper` 中新增 `#modbusView` 容器，与 `#terminalOutput` 同级
- 切换方式：`display: flex/none`
- Modbus 激活 → 终端输出隐藏，Modbus 视图显示
- Modbus 关闭 → Modbus 视图隐藏，终端输出恢复
- 右侧栏 Modbus 面板在激活时自动折叠并禁用

## 循环发送

### 状态变量

```js
let modbusCycling = false;
let modbusCycleTimer = null;
let modbusCycleCount = 0;
```

### 交互

| 操作 | 行为 |
|------|------|
| 点击「开始循环」 | 立即发一次，然后按间隔定发送 |
| 点击「■ 停止」 | 停止循环，清理定时器 |
| 循环中串口断开 | 自动停止 |
| 关闭 Modbus 模式 | 自动停止 |
| 间隔框 | type=number, 100-60000ms, 默认 1000 |

### 发送逻辑

```
modbusCycling = true
→ modbusSend() 立即发送
→ setInterval(间隔ms):
    如果 modbusCycling && modbusActive → 再次 modbusSend()
    否则 clearInterval

停止 → modbusCycling = false → clearInterval
```

### 视觉反馈

- 循环中按钮文字变为「⟳ 循环中...」
- 状态栏显示 `CYCLE: N`
- 停止后按钮恢复

## 联动

- `modbusToggleActive()` 增加视图切换逻辑
- Modbus 主视图中的请求构建器复现右侧栏的控件功能
- 右侧栏 Modbus 面板在激活时隐藏
- 所有右侧栏的 Modbus 函数（modbusSend 等）仍然复用

## 边界情况

- 循环发送中禁用 Modbus → 自动停止循环
- 独立串口断开 → 自动停止循环
- 切换模式（共享↔独立）→ 自动停止循环
- 视图切换时保持 TX/RX 帧显示状态

## CSS 样式

新增 ~40 行，Modbus 视图的 flex 布局、分区，沿用现有设计系统。
