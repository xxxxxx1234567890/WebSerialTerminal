# Modbus RTU 调试工具 — 设计文档

## 概述

在 WebTerm Pro 右侧工具箱中新增一个 Modbus RTU 调试面板，复用现有串口连接，提供标准 Modbus RTU 功能码的请求构建、发送、响应解析和多格式数据显示。

## 功能范围

基本读写功能（A 级）：
- 8 种标准 Modbus RTU 功能码：01, 02, 03, 04, 05, 06, 15(0F), 16(10)
- 手动输入 slave ID、地址、数量
- 请求/响应 HEX 帧完整显示
- 多格式数据解析（HEX/U16/I16/F32）
- 线圈可视化开关状态灯
- CRC16 自动计算与验证
- 异常码解析
- 响应时间统计
- 历史报文日志

## 布局

右侧工具箱新增折叠面板，与现有校验计算、浮点数转换等工具并列。

### 折叠面板结构

```
◈ Modbus RTU 调试          [▼]
├── 请求构建器
│   ├── 从站 ID (1-247)
│   ├── 功能码下拉 (8种)
│   ├── 起始地址 / 数量
│   ├── 写入数据 (写操作时启用)
│   ├── 地址格式切换 (DEC/HEX)
│   └── [发送按钮]
├── TX/RX 帧显示
│   ├── TX: 蓝色, CRC 琥珀色标注
│   └── RX: 绿色, 带响应时间 + 时间戳
├── 响应解析
│   ├── 寄存器模式: 逐行 HEX/U16/I16/F32
│   ├── 线圈模式: 位图开关灯
│   └── 异常码: 红色高亮 + 中文描述
└── 日志标签页
    └── 历史记录列表: 时间, 摘要, 状态
```

## 请求构建器

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| 从站 ID | number | 1-247 | 默认 1 |
| 功能码 | dropdown | 01-06, 15, 16 | 带描述文字 |
| 起始地址 | number | 0-65535 | 支持 DEC/HEX 输入 |
| 数量 | number | 1-2000 | 受限于报文大小 |
| 写入数据 | text | HEX 格式 | 写操作时激活, 只读不可用 |

功能码选项:
- 01 - Read Coils
- 02 - Read Discrete Inputs
- 03 - Read Holding Registers
- 04 - Read Input Registers
- 05 - Write Single Coil
- 06 - Write Single Register
- 15 (0F) - Write Multiple Coils
- 16 (10) - Write Multiple Registers

## 帧构造与发送

### Modbus RTU 帧格式

```
[Slave ID: 1 byte] [Function Code: 1 byte] [Data: N bytes] [CRC16 Low: 1 byte] [CRC16 High: 1 byte]
```

### 发送流程

1. 根据功能码和输入字段构造数据部分
2. 计算 CRC16（多项式 0x8005, 初始值 0xFFFF, 小端序输出）
3. 通过 `writer.write()` 发送原始字节
4. 记录发送时间戳，显示 TX 帧
5. 启动 500ms 响应超时定时器

## 响应解析

### 接收流程

1. 发送后，readLoop 中读取的数据同时投递到 Modbus 解析器
2. 解析器积累字节直到收到完整 RTU 帧（通过长度字段判断）
3. 验证 CRC16
4. 解析 PDU 数据
5. 超时未收到响应则标记超时

### 正常响应解析

- **FC 01/02**（线圈/输入）：提取字节位图，逐位显示 ON/OFF 状态灯
- **FC 03/04**（寄存器）：按 2 字节/寄存器提取，计算多格式值
- **FC 05/06**（写单）：回显验证，显示写入成功
- **FC 15/16**（写多）：回显地址+数量，显示写入成功

### 多格式值计算

对每个 16-bit 寄存器值：
- HEX: `00 01` 格式显示原始字节
- U16: 无符号整数
- I16: 有符号整数（补码）
- F32: 两个连续寄存器组合为 32-bit 浮点数（暂固定小端序，后续可扩展大小端切换）

### 异常响应

- 识别 FC | 0x80 异常响应
- 解析异常码并显示中文描述：

| 异常码 | 描述 |
|--------|------|
| 01 | 非法功能码 |
| 02 | 非法数据地址 |
| 03 | 非法数据值 |
| 04 | 从站设备故障 |
| 05 | 确认 |
| 06 | 从站设备忙 |
| 08 | 存储奇偶性错误 |
| 0A | 网关路径不可用 |
| 0B | 网关目标无响应 |

## 日志

- 每笔发送记录：时间戳、FC 摘要、响应时间、状态
- 颜色编码：绿色（成功）、红色（超时/异常）、琥珀色（异常码）
- 清空按钮
- 日志在面板中滚动显示，保留最近 100 条

## 数据流

```
[请求构建器] → 构造帧 + CRC16 → writer.write() → 串口设备
                                                    ↓
readLoop ← 串口设备 ← [Modbus 设备响应]
    ↓
[终端显示] + [Modbus 解析器]
                ↓
          [响应解析面板] → 多格式值/线圈灯/异常码
```

## CRC16 实现

标准 Modbus CRC16:
- 多项式: 0x8005
- 初始值: 0xFFFF
- 结果异或: 0x0000
- 字节序: 小端（低字节在前）
- 已有代码中的 CRC 函数可适配复用

## 集成点

- **发送**: 复用全局 `writer` 写入原始字节
- **接收**: 在 `readLoop()` 中增加 Modbus 数据分流逻辑
- **状态**: 发送前检查 `isConnected`
- **显示**: CRC 校验等函数可复用现有工具函数
